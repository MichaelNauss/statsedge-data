# statsedge-data
Public data files for the Build Your Own Book page on statsedgetrading.com. Two files only, replaced on the first market day of each month by the Stats Edge pipeline:

- bob_data.json: the two books' per-system daily returns (encoded), system list, pack ids, data-through dates.
- monthly.json: the month-by-month table (backtest months from the packs; live months from the published record, frozen once published).

Hypothetical backtest figures and the published live record, as described on the page. Not investment advice.
